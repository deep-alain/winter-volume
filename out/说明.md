# 竖向冬日音量键

音量是一段向上的雪山旅行。把音量向上推，缆车载着戴毛线帽的小人，从山脚木屋出发，经过松林与雪线，最后到极光下拍照。音量从 0% 连续调到 100%；房间从雪日的浅青色变成暮色，再进入蓝色冬夜。

竖向版本最初在独立目录 `experiments/glass-volume` 制作，现整理为独立项目，目标仓库为 `deep-alain/winter-volume`。本项目保留源码、成片与配图；没有发布到 X 或部署网站。

## 画面从后到前

| 层 | 内容与音量的关系 |
| --- | --- |
| 天空 | 四档光照对应雪日、黄昏、暮蓝、冬夜；星星随夜色出现，高音量出现极光 |
| 远山 | 雪峰和岩面采用各自的四套材质色；远景视差最小 |
| 松林与雪坡 | 中景视差；18%～76% 可看到枝头落雪 |
| 山脚木屋 | 38% 以上亮窗，烟囱的烟随音量升高飘得更远 |
| 雪兔 | 20%～80% 出来跳跃，入夜后躲回去 |
| 轨道、缆车、小人 | 随音量垂直升降；低音量打盹，随后喝热饮，45% 以上招手，83% 以上举相机留影；55% 以上车灯亮起 |
| 前景 | 旗帜随音量增强摆动，雪花从 9 片增加到 28 片；雪花避开小人的脸 |
| 玻璃滑块 | 跟随缆车升降，放大车厢和小人；快速移动时纵向拉伸、横向收缩，停下后轻微回摆 |

## 像素与玻璃

- CPU 每帧绘制 76×144 场景，输出普通光照、全亮画面和发光三个 RGBA 像素缓冲。
- 精灵由填充形状构成，自动生成 1 像素外轮廓，并增加顶部亮面、底部暗面。
- 每种材质有四个独立配色键。4×4 Bayer 有序抖动只选择相邻配色键中的一个，不对世界像素混色。房间背景与玻璃颜色可平滑过渡。
- 画布逻辑尺寸 96×176；按设备像素取整数倍率，竖向控制不超过约 230×422 CSS 像素。像素纹理用 NEAREST 采样，CSS 也关闭平滑。
- WebGL2 用一个覆盖画布的片元着色器完成玻璃：约 1.28 倍放大、弯折、边缘 RGB 色散、暗折射带、亮边、Fresnel 色调、左上长高光与右下光点。镜内使用全亮缓冲。
- 发光缓冲在着色器中以邻域采样柔化后叠加。玻璃会在世界上投下软阴影。胶囊以外透明，输出使用预乘 alpha。
- WebGL2 不可用时自动使用 2D Canvas，保留清晰像素和玻璃环。

## 交互与运行

- 向上拖动增大音量；真实原生 range 保留屏幕阅读器支持，使用竖向 ARIA 描述、可见键盘焦点和隐藏状态播报。
- ↑ / → 增加 2%，↓ / ← 减少 2%；按住 Shift 调整 10%；Home / End 到两端；Enter / Space 跳到另一端。
- 指针拖动使用更硬的弹簧，释放后滑块停留在目标音量。视差跟随指针，并加入缓慢闲置摆动。
- 系统偏好减弱动态时立即定位，停止场景运动和视差。深色模式默认从冬夜端打开。
- `?demo=1` 播放 10 秒指针演示；任何真实指针或键盘输入立即接管。
- `window.__render(t)` 每次从固定种子的新世界和新运动状态开始，按固定 60 fps 推进到 t 秒（最长 120 秒），可用于重复取帧。`?t=4.2` 可直接查看固定演示帧。
- React 只挂载引擎，不在动画帧里更新 React 状态。rAF 的 dt 上限为 0.05 秒。dispose 取消动画帧，通过同一个 AbortController 解除全部监听，并删除所有 GL 对象。

本地运行：

```powershell
cd winter-volume
npm ci
npm run dev
```

验证命令：

```powershell
npm run build
npm run lint
npm test
```

## 已知边界

- 当前是 0%～100% 音量控件的视觉与交互实现，尚未连接系统音量或实际音源。
- 2D 降级保留场景和圆环，不提供 WebGL 的真实折射、色散与模糊发光。
- 手机尺寸已用浏览器视口验证，尚未在实体触屏设备上验证手势。

`out/竖向预览.jpg` 与 `out/手机预览.jpg` 为浏览器实际渲染截图。

## 循环视频与 X 配图

新媒体放在 `out/x-vertical/`。包括 1080×1350 竖版、1080×1080 方版 MP4，以及极光封面、山脚日景、玻璃近景、四阶段拼图四张 PNG。视频为 12 秒、30 fps，H.264 High/yuv420p + AAC LC，带轻柔原创合成环境音；没有发布到 X。

缆车在 1～3.4 秒顺滑上升，在山顶停留至 6 秒，随后下降至 9.2 秒，剩余时间在山脚休息。固定 60 fps 运动先运行四轮预热，再以 30 fps 取帧。世界的 `loopDuration` 可选参数让所有环境运动在同一个周期闭合；雪花持续向下，并在场景以外重新进入。

导出工具直接调用同一个 CPU 像素世界与 WebGL 玻璃着色器，未用简化效果替代玻璃。视频的 360 帧均由浏览器实际绘制，配图使用同一渲染流程。编码采用固定量化的独立帧，避免首尾因编码参考帧不同而出现亮度变化。

实际 MP4 已完整解码并检查首尾六帧。竖版切口的平均 RGB 变化为约 0.039，附近普通帧最大变化约 0.065；方版分别约 0.037 与 0.047（通道取值范围 0～255）。音轨检查覆盖名义 12 秒边界，忽略 AAC 尾部填充样本。检查详情见 `out/x-vertical/media-check.json`，首尾拼图见 `out/x-vertical/seam-contact.png`。

重新生成：在项目目录执行 `npm ci` 安装依赖（包含离线媒体工具的开发依赖 `@napi-rs/canvas`、`ffmpeg-static`），然后执行 `npm run media:serve`，打开本地 `http://127.0.0.1:4175/media.html` 并点击导出；完成后执行 `npm run media:encode` 和 `npm run media:check`。中间帧保存在忽略目录 `.local/vertical-frames/`，不会进入 Git。
